# BİLGE AKADEMİ

Türkçe, mobil uyumlu beş modüllü eğitim uygulaması. React + TypeScript + Vite.

## Kurulum

Node.js 20+ gereklidir.

```bash
npm install
npm run dev
```

Üretim derlemesi: `npm run build`.

## Modüller

- Öğrenci takibi: öğrenci ekleme, not düzenleme, devamsızlık, CSV dışa aktarma
- Şiir atölyesi: şiir yazma, kaydetme, silme, dize/kelime sayısı
- Tarih atlası: başlangıç kronolojisi ve arama
- Matematik: doğrusal denklem ve aritmetik çözücü, mini alıştırma
- Felsefe: filozof kartları ve kural tabanlı Sokratik sorular

## Sınırlar

Bu MVP/demo sürümüdür. Gemini API, kimlik doğrulama, harita, PDF ve çok kullanıcılı veritabanı henüz yoktur. Öğrenci ve şiir kayıtları localStorage üzerinde tutulur. Gerçek öğrenci veya kişisel verilerle üretim ortamında kullanmayın.
